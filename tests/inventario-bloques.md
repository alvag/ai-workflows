# Inventario histórico de bloques ejecutables

Este documento es la sede única de los inventarios exigidos por AC-3, AC-6, AC-8 y AC-16.
Toda evidencia histórica se extrajo del commit `5013b4589d5b6429f9705539268eb0d8ac7ae3fc` mediante `git show`; el árbol de
trabajo no es autoridad para estos conteos.

La identidad de un caso es siempre `matriz/caso`. Los 397 casos contienen 347
nombres locales distintos y `positivo` aparece 28 veces.

## Convenciones

Las únicas clases son: guarda, infraestructura de tests, receta de invocación de CLI,
operación portable y documentación que se ejecuta. La clase propuesta siempre es una de
ellas. Duda conserva una segunda candidata para adjudicación humana sin cambiar la propuesta.
En las tablas, \u007c representa un pipe literal y \n un salto dentro de un string JSON.

```python
"""Parse the restricted Markdown pipe tables used by skill guards."""

from __future__ import annotations

__all__ = ["parsear_tabla_pipe"]


def parsear_tabla_pipe(texto: str) -> list[list[str]]:
    """Return pipe-table rows, omitting separators and preserving case."""
    filas: list[list[str]] = []
    for linea in texto.splitlines():
        linea = linea.strip()
        if not (linea.startswith("|") and linea.endswith("|")):
            continue
        celdas = [celda.strip() for celda in linea[1:-1].split("|")]
        if celdas and all(celda and set(celda) <= {"-", ":"} for celda in celdas):
            continue
        filas.append(celdas)
    return filas
```

## Adjudicación de las clases dudosas

El censo marcó **ocho** filas con una clase alternativa. Las ocho las resolvió el conductor —la
clasificación es una adjudicación humana y así está declarado en el plan—, y las ocho quedaron **en
la clase propuesta**. Que la duda se levantara y no cambiara nada no la vuelve inútil: es lo que
permite que el criterio quede escrito en vez de suponerse.

**El criterio, que no es el que sugiere el nombre de la clase.** `guarda` se lee como «verifica un
predicado», pero su contenido operativo es **«migra a la skill»**. Un bloque puede no emitir ningún
veredicto y ser `guarda` igual. El corte real es otro: **si el bloque se puede unificar en un solo
script, migra; si su gemelo PowerShell existe porque la operación es intrínsecamente del shell, se
conservan las dos variantes.**

| fila | duda | adjudicado | fundamento |
|---|---|---|---|
| `apertura` | operación portable | **guarda** | tres líneas de `awk` que extraen una entrada por ID: transformación de texto, no operación de shell. Un script la unifica con su gemelo. No emite veredicto y aun así migra |
| `split` | operación portable | **guarda** | ídem: parte la salida cruda en índice y detalle. Su gemelo (F14) hace lo mismo con `Get-Content`/`Add-Content` — es el caso canónico que esta migración viene a eliminar |
| `split-paginado` | operación portable | **guarda** | además sí verifica: tiene `# Predicado:`, emite `GUARD:` y corta con código distinto de cero |
| F14 | operación portable | **guarda** (gemelo de `split`) | se retira con su bloque base, porque el base migra |
| F16 | operación portable | **guarda** (gemelo de `apertura`) | ídem |
| F06 | operación portable | **receta de invocación de CLI** | preflight/launch/resume del transporte: depende del CLI, no es texto. Se conserva con sus dos variantes |
| F39 | operación portable | **receta de invocación de CLI** | ídem |
| F40 | operación portable | **receta de invocación de CLI** | ídem |

**Por qué importaba resolverlas y no dejarlas pasar.** Las dos clases candidatas tienen destinos
**opuestos**: `guarda` migra y su gemelo se retira; `operación portable` conserva las dos variantes.
Dejar `apertura` y `split` del lado equivocado habría conservado dos gemelos PowerShell que este
cambio existe para borrar; dejar F06, F39 y F40 del lado equivocado habría borrado recetas de
invocación que tienen que sobrevivir.

# Sede del corpus diferencial

Existe para ejercer, sobre entradas controladas, cada forma tipada que usan las trece recetas. Las
sedes reales sirven para el positivo, pero no permiten provocar los bordes: no se puede pedirle a
una skill que tenga un encabezado duplicado para ver qué hace la cardinalidad.

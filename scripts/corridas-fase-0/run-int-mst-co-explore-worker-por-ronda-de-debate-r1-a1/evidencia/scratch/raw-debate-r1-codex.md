2. **Entrada necesaria:** la decisión concreta, las opciones, el contexto relevante del código o artefactos, las restricciones y, desde R1, la postura actual del conductor.

3. **Salida:** una respuesta estructurada con postura, fundamentos, trade-offs y riesgos/incógnitas; en rondas de cruce, crítica, postura actualizada y convergencias. Esa salida se cosecha para construir una síntesis atribuida por familia que conserva los desacuerdos y deja la decisión al usuario.

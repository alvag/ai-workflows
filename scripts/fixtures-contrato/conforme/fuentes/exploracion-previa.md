# Exploración previa sintética

El **segundo** documento fuente del corpus. Existe porque con uno solo no se distinguen los dos
mutantes de atribución: una fuente equivocada —la afirmación vive en otro documento del corpus— sería
indistinguible de una afirmación que no vive en ninguno, y el modo podría emitir el mismo veredicto
para las dos.

## Lo que esta exploración afirma

- Un archivo de política de invocación sintética queda definido por su extensión.
- El inventario sintético de sitios se deriva recorriendo el árbol completo.
